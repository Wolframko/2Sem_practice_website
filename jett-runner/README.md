# Jett Run

Пиксельная анимация и мини-игра: Джетт из VALORANT бежит по крышам на закате,
перепрыгивает ящики и турели, проскальзывает под дронами и делает рывок сквозь
препятствия — как динозаврик в Chrome.

Открой `index.html` в браузере — ничего устанавливать не нужно. Сначала Джетт бежит
сама (автопилот), нажми **Пробел** или тапни по сцене, чтобы играть.

## Управление

| Клавиша | Действие |
| --- | --- |
| Пробел, ↑, W | прыжок: чем дольше держишь, тем выше; в воздухе — парение (Drift) |
| ↓, S | пригнуться; в воздухе — быстро приземлиться |
| E, Shift | рывок сквозь препятствие (Tailwind), перезарядка 5 с |
| P, Esc | пауза |
| M | звук |

На телефоне: тап по сцене — прыжок, кнопки под сценой — подкат и рывок.

## Как устроено

- `index.html` — страница, счёт, ранги и оверлеи поверх игры.
- `style.css` — оформление в стиле интерфейса VALORANT.
- `sprites.js` — вся пиксельная графика. Джетт и препятствия нарисованы текстом
  (один символ — один пиксель), позы собираются из суставов, фон генерируется кодом.
- `game.js` — физика, появление препятствий, автопилот, управление и отрисовка на `<canvas>`.
  Автопилот «проигрывает» ближайшие секунды игры вперёд и выбирает момент для прыжка,
  подката или рывка.
